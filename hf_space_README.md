# EPS Dynamic-GNN — Live Demo

Interactive demo of a Dynamic Graph Neural Network for satellite Electrical
Power System fault diagnosis. Pick a fault scenario, run a fresh simulated
orbit, and watch all four trained models (CNN, LSTM, Static-GNN,
Dynamic-GNN) predict the fault live — including a scrubbable view of the
Dynamic-GNN's learned adjacency matrix A(t) evolving across the
eclipse-to-sunlit transition.

Full code, paper, and results: see the linked GitHub repository.
